# twitch-stream-information-manager
A simple tool to effortlessly switch between different games and stream information presets.  Works on multiple Twitch accounts.

1. Launch the exe of the latest build.
2. ADD your Twitch account and follow the instructions to authorize it with the app.
3. Create as many NEW PRESETS as you want
4. Click UPDATE TWITCH to apply whichever preset you have selected.
